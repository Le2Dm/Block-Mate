# BLOCK MATE · 60482 설명서 QR 연결

모드 1은 설명서의 LEGO Builder QR을 읽어 60482 소방차 조립 가이드를 시작합니다.

## 실행

`dist/`를 HTTPS 호스팅 또는 로컬 웹 서버로 열고 `index.html`에서 **설명서 QR로 시작**을 선택합니다. `import-set.html`로 바로 들어가도 됩니다. 기존 배포 주소와 접근 권한을 유지합니다. 별도의 API 키는 필요하지 않습니다.

## 사용 흐름

1. QR을 카메라로 읽거나 QR 사진을 선택합니다. 사진은 기기에서 처리되며 업로드되지 않습니다.
2. 확인된 60482 카드에서 **이 설명서로 조립 시작**을 누릅니다. 세트 번호 `60482` 직접 입력도 같은 결과입니다.
3. 공식 설명서 5–60쪽을 바탕으로 만든 28개 과업을 3D로 진행합니다. 기본 화면은 3D이며 공식 연결 그림은 오른쪽 아래의 작은 참고 카드에서 확인합니다. 이미지를 누르면 확대되고, 접기/펼치기를 지원합니다. 단계가 바뀌면 참고 그림도 자동으로 바뀝니다. 좁은 화면에서는 3D 아래 오른쪽에 배치해 모델을 가리지 않습니다.
4. 부품 이미지는 공식 설명서의 부품 목록에서 가져온 것이며, 36종·67개의 엘리먼트 번호와 전체 수량을 표시합니다.
5. 화면에서 부품을 직접 선택하거나, 카메라를 켜고 부품 자리/종류를 수동 등록한 다음 검지로 그 자리를 가리킵니다.
6. 음성을 켜고 **이거 맞아? / 어디에 끼워? / 연결했어**라고 말합니다. 같은 질문을 텍스트 입력창으로 전달할 수도 있습니다.
7. 모든 28개 과업은 **3D 연결 구조** 탭에서 회전·고정 시점·분해도를 지원합니다. 초록색 테두리는 해당 단계에 추가하거나 이동할 부품을 표시합니다. ‘연결 위치 보기’는 해당 부품이 들어가는 동작을 재생합니다. 손으로 조작하려면 **가이드 조작 켜기**를 선택합니다.
8. 상단 단계 선택에서 이미 조립한 위치로 이동할 수 있습니다. 28단계 후에는 완성 그림을 보여줍니다.

## 구현 범위

- 실제 작동: 기기 내 QR 사진/카메라 판독, 설문 QR 구분, 세트 번호 추출, 60482의 준비된 설명서·부품 데이터 로딩, 단계별 필요한 부품 비교, 공식 연결 그림, 손 관절 인식과 등록한 자리 지정, 브라우저 음성 명령.
- 지원 세트는 **60482 한 개**입니다. QR을 찍을 때 LEGO의 비공개 데이터를 추출하거나 임의 세트의 설명서를 자동 변환하는 기능은 아닙니다. 60482 공식 설명서 자료를 미리 준비하여 제공합니다.
- 3D는 **67개 실물 부품에 대응하는 전체 조립 과정의 시연 모델**입니다. 일부 특수 몰드, 인쇄 무늬, 부품 밑면과 연결 공차는 단순화했으며 공식 CAD 또는 자동 PDF 변환 결과가 아닙니다. 실제 조립 정확도는 실물 비교로 추가 검증해야 합니다.
- 카메라가 실물 부품의 종류·색상·연결 완료를 자동 판정하지 않습니다. 사용자가 등록/선택한 종류와 현재 단계의 부품 목록을 비교합니다.
- 같은 단계에서 부품 종류가 여러 개인 경우, 선택한 부품이 그중 하나인지 확인하고 해당 수량을 표시합니다. 조립한 묶음을 다시 쓰는 단계는 새 부품으로 중복 계산하지 않습니다.
- 사용자 사진·카메라 영상·녹음·QR의 고유 토큰은 서버나 저장소에 기록하지 않습니다. 진행 상태는 현재 탭에서 유지합니다.
- 음성 인식은 브라우저 제공 서비스를 사용하므로 브라우저에 따라 외부 음성 처리가 이뤄질 수 있습니다.
- 기본 5개 블록 연습은 `mode1.html`에서 계속 사용할 수 있습니다. 모드 2는 기존 바디스토밍 시제품입니다.

## 자료

- 공식 설명서: https://www.lego.com/cdn/product-assets/product.bi.core.pdf/6606824.pdf
- 공식 세트 안내: https://www.lego.com/en-us/service/building-instructions/60482

# BLOCK MATE · Mode 1

카메라 손동작과 브라우저 음성 명령으로 조립 가이드를 조작하는 작동 시제품입니다. `dist/mode1.html`이 이번 버전의 주 화면입니다. 기존 홈에서도 ‘조립 가이드’ 또는 ‘모드 1 사용하기’로 들어갈 수 있습니다.

## 실제 작동하는 기능

- MediaPipe Hand Landmarker로 최대 두 손의 21개 관절을 기기에서 인식합니다.
- 기본 상태는 조립하기입니다. 블록을 집거나 움직이는 손동작이 모델을 회전시키지 않습니다.
- 가이드 조작 상태에서 한 손 엄지·검지 집기로 회전, 두 손 집기로 분해도를 벌리거나 모읍니다.
- 정면·측면·윗면·입체 시점, 확대·축소, 분해도 슬라이더, 연결 위치 강조를 버튼과 명령으로 사용할 수 있습니다.
- 부품 자리와 종류를 먼저 직접 등록하면, 해당 자리 안을 검지로 0.7초 가리켜 부품을 선택합니다. 가리킨 대상과 현재 단계의 필요 부품을 비교합니다.
- 질문을 먼저 하면 대상을 선택할 때까지 질문을 유지합니다. 단계가 바뀌면 선택·질문을 비우고 조립 상태로 돌아갑니다.
- 실제 연결 완료는 사용자의 확인 또는 “연결했어” 발화로 진행합니다.

## 준비물과 사용 순서

연습 모델은 2 × 4 기본 블록 2개와 2 × 2 기본 블록 3개, 총 다섯 개를 사용합니다. 특정 제품의 설명서나 자동 생성 모델이 아닌, 연결 구조를 보여주기 위한 연습 구조물입니다.

1. HTTPS 배포 주소 또는 localhost에서 모드 1을 엽니다. file:// 더블클릭 실행은 지원하지 않습니다.
2. ‘손 인식 준비’로 모델을 준비하고 ‘카메라 켜기’로 영상을 켭니다.
3. 카메라와 부품 자리를 고정하고, ‘실제 부품 자리 등록’에서 부품을 둘러싼 영역을 그린 뒤 실제 종류를 지정합니다. 카메라를 다시 켜면 자리는 다시 등록합니다.
4. ‘음성 켜기’를 선택하거나 텍스트 명령을 사용합니다.
5. 부품을 가리키고 “이거 맞아?”, “어디에 끼워?”라고 질문합니다.
6. “가이드 조작할게”로 전환한 다음 손으로 회전하거나 분해도를 조절합니다. “옆에서 보여줘”, “위에서 보여줘”로 시점을 고정할 수 있습니다.
7. “다시 조립할게”라고 말하고 실물을 연결합니다. “연결했어”로 다음 단계로 이동합니다.

## 명령 예시

가이드 조작할게 / 다시 조립할게 / 이거 맞아? / 어디에 끼워? / 분해해서 보여줘 / 다시 모아줘 / 정면 / 옆에서 보여줘 / 위에서 보여줘 / 입체로 보여줘 / 더 크게 / 더 작게 / 이전 단계 / 연결했어 / 다시 읽어줘 / 취소 / 처음부터 / 음성 꺼줘

음성 입력과 TTS는 브라우저 지원·권한에 따라 작동합니다. 음성 인식은 브라우저가 제공하는 서비스를 사용하므로 인터넷 연결이 필요할 수 있습니다. 실패하면 버튼·모델 드래그·직접 입력으로 계속할 수 있습니다.

## 구현 경계

부품 종류는 사용자가 자리 등록 또는 직접 선택으로 지정합니다. 카메라가 임의의 LEGO 부품 종류를 자동 판별하는 기능은 아닙니다. 등록 후 부품과 카메라를 움직이면 자리도 다시 등록해야 합니다. 실제 블록 회전을 자동 추적하거나 실제 조립 완료를 자동 판정하지 않습니다. 답변은 현재 단계에 연결된 안내이며 생성형 AI API는 사용하지 않습니다. 모드 2는 기존 바디스토밍 버전을 유지합니다.

사진·녹음·등록 자리·진행 기록은 서버에 저장하지 않습니다. 현재 탭을 새로고침하면 초기화됩니다. 이미지 모델은 손 관절만 감지하며 블록 종류를 분류하지 않습니다.

## 실행·배포

빌드와 패키지 설치, 환경변수, API 키가 필요 없는 정적 HTML/CSS/JavaScript 프로젝트입니다. `dist` 전체를 웹 서버로 제공하면 됩니다.

Python이 있는 경우 프로젝트 폴더에서 `python3 -m http.server 5192 --directory dist`를 실행하고 `http://localhost:5192/mode1.html`을 엽니다. Vercel에는 `dist` 내용을 ZIP 최상단에 넣어 Vercel Drop으로 올릴 수 있습니다. 손 인식 런타임·WASM·모델을 포함하므로 `vendor` 폴더를 빠뜨리지 않아야 합니다.

Google MediaPipe Tasks Vision 1.2.3과 HandLandmarker float16 v1 모델을 포함합니다. 출처와 라이선스는 `dist/vendor/README.txt`, `dist/vendor/LICENSE`에 있습니다. 손 인식은 최초 로드 후 외부 CDN을 사용하지 않습니다.

## 검증과 한계

`npm test`는 명령 분류, 조립 모드 입력 차단, 좌우 반전 좌표, 손 이탈 후 재진입, 두 손 분해도, 영역 중복 처리와 가리키기 체류를 검증합니다. 브라우저에서는 모델 로딩과 빈 프레임 추론, 시점·분해도 조작, 질문 후 부품 선택, 잘못된 부품 비교, 단계 진행과 완료를 확인했습니다. 실제 사용자의 카메라 영상과 마이크 발화는 자동 승인하지 않았으므로, 물리적 손동작 인식률과 조명·카메라 배치·음성 인식률은 시연 기기에서 추가 검증해야 합니다.

기존 바디스토밍 참고 문서는 `docs/bodystorming.md`에 보관했습니다.
