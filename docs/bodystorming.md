# BLOCK MATE

블록 조립과 자유 창작을 위한 바디스토밍용 웹 시제품입니다. 별도 설치와 API 키 없이 배포 링크에서 사용할 수 있습니다.

## 체험 흐름

- 조립 가이드: 부품 지정 → ‘이거 맞아?’ → 부품 비교 → ‘어디에 끼워?’ → 연결 위치 보기 → 직접 다음 단계로 이동.
- 자유 창작: 블록 확인 → 부품 목록과 개수 수정 → 제작 요청 → 작품 제안 → 공통 조립 가이드.
- 인식 실패: 상단 시연 패널에서 ‘판단 불가’ 또는 ‘손에 가려짐’을 선택하고 재시도·직접 선택을 확인합니다.
- 부품 부족: 시연 패널에서 ‘바퀴가 없는 상황’을 선택하면 자동차 시작이 비활성화되고 다른 작품을 선택할 수 있습니다.

## 바디스토밍 진행

참여자 앞에 실제 블록을 놓고 노트북 또는 태블릿을 설치합니다. 참여자는 실물을 가리키며 질문합니다. 진행자는 시연 패널에서 관찰한 부품과 들은 질문을 각각 대신 입력합니다. 질문이 먼저 입력되면 대상을 지정할 때까지 기다렸다가 답변을 이어갑니다. 잘못된 부품이면 연결 위치 대신 차이를 보여줍니다. 카메라 없이 예시 화면의 블록을 선택해도 됩니다. ‘관찰 기록’에서 메모를 추가하고 종료 전에 JSON 파일로 내려받습니다. 새로고침하면 기록이 초기화됩니다.

## 실제 동작과 모의 동작

실제 동작: 화면 이동, 회전 가능한 입체 예시, 부품 직접 선택·비교, 부품 수량 수정, 부족한 부품 계산, 단계 이동, 관찰 기록·다운로드. 카메라 영상은 권한 허용 시 기기에서 표시하고 사진은 현재 탭의 메모리에서만 사용합니다. 음성 입력과 음성 안내는 브라우저 지원·권한에 따라 작동합니다.

모의 동작: 사진 속 블록 자동 식별, 실물 포인팅 인식, AI 답변, 자유 조립안 생성. 사진에서도 고정된 예시 부품 목록을 사용합니다. 질문은 미리 정의한 의도로 분류하고, 제작 요청은 준비된 자동차·로봇·벤치 예시를 보여줍니다. 외부 AI API나 사용자 계정·서버 저장 기능은 연결하지 않았습니다.

입체 모델과 부품 수량은 인터페이스 검토를 위한 개념 예시입니다. 특정 LEGO 제품의 CAD 모델이나 물리적으로 검증된 조립 설명서가 아닙니다. 실제 블록을 사용하는 검증 전에는 팀이 대상 제품·단계에 맞는 모델과 안내로 교체해야 합니다.

## 로컬 실행

`dist` 폴더를 정적 웹 서버로 제공하면 됩니다. Python이 있는 환경에서는 프로젝트 폴더에서 `python3 -m http.server 5192 --directory dist`를 실행한 다음 `http://localhost:5192`를 엽니다. 서버가 없는 환경에서는 배포 링크를 이용하세요. 파일을 더블클릭하는 file:// 방식은 JavaScript 모듈과 카메라 권한 제한으로 지원하지 않습니다.

HTML, CSS, Vanilla JavaScript로 구현했습니다. 설치할 패키지·빌드 단계·환경변수·API 키는 없습니다. 핵심 파일은 dist/app.js(화면과 상호작용), dist/model.js(예시 데이터·규칙), dist/render.js(입체 도식), dist/style.css입니다.

## 확인한 항목

맞는 부품/다른 부품 비교, 재선택, 연결 위치 표시, 단계 이동과 완료, 부품 수량 수정, 부족한 부품 안내 및 조립 차단, 대안 작품 진입, 가림 상태 복구, 관찰 메모와 다운로드, 데스크톱·태블릿·모바일 화면을 확인했습니다. 실제 카메라·음성 권한은 자동 승인하지 않았으므로 사용 기기에서 별도로 확인해야 합니다.

## 멀티모달 바디스토밍 (개정)

홈의 ‘진행 방법 보기’에서 역할을 확인합니다. 조립 화면 상단에는 가리킨 대상, 말한 질문, 응답 상태가 나란히 표시됩니다.

1. 참여자가 실제 블록을 가리키며 ‘이거 맞아?’라고 질문합니다.
2. 진행자가 ‘시연 패널 → 진행자 창 따로 열기’를 선택합니다. 두 창은 같은 브라우저와 같은 사이트에서만 연결되며 다른 기기에서는 연결되지 않습니다. 여러 사용자 화면을 열었다면 진행자 창에서 연결할 화면을 선택합니다.
3. 진행자가 실제 가리킨 부품과 말한 질문을 각각 전달합니다. 질문을 먼저 입력해도 기억하며, 대상이 확인되면 응답합니다.
4. 참여자가 물체를 좌우로 돌리면 진행자가 대응하는 방향 버튼을 눌러 모델 방향을 수동으로 맞춥니다. 자동 방향 인식이 아닙니다.
5. 참여자가 연결하고 ‘연결했어’라고 말하면 진행자가 이를 전달해 다음 단계로 이동합니다. 단계 전환 시 이전 대상과 질문은 비워집니다.
6. 인식 실패 상황에서 재시도하면 질문과 단계는 유지되며, 다시 지정한 대상을 기준으로 응답합니다.

실제 음성 입력은 브라우저 Web Speech 지원·권한에 따라 사용할 수 있습니다. 이번 수정은 실제 손가락 제스처 추적 모델을 추가한 것이 아니라 물리적 행동과 그에 대한 반응을 바디스토밍에서 검증하도록 한 것입니다. 영상·사진·관찰 기록은 진행자 창에 보내지 않으며, 창 간에는 현재 단계·선택한 부품 종류·질문 문장·모델 각도·응답 상태만 브라우저 내부에서 전달됩니다.
